# Instagram 광고 즉시 넘김 · 초기 설계

0.2.1에서 광고 완주를 기다리지 않는 즉시 넘김과 별도 ON/OFF 토글을 적용했다. 아래는0.2.1 당시 설계이며,0.2.4의 반복횟수와 독립된 광고 동작은 [릴리스 기록](releases/v0.2.4.md)을 따른다. 실제 결과는 [검증 기록](VERIFICATION.md)에 구분한다.

## 조사와 기존 버전 시험에서 확인한 사실

- 0.2.0 실제 인앱 숫자/화살표/100입력거부/0·99경계/두탭모드/플로팅위치/X/표시OFF·실행유지 시험 수행. 짧은 라디오 오른쪽 빈 영역 무반응 수정(D-014),하드웨어Enter 뒤 비조작 컨테이너 전체강조는 focus highlight 해제로 수정.
- 첫 일반 릴스는 재생바가 실제로 없고 제품·동일UIAutomator 모두 시간정보를 못 읽음. **재생바 없음은 광고의 증거가 아니다.**
- 다음21.708초 일반릴스는0.2.0 서비스에서1/2→2/2 후 다음 광고로 실제 이동. 요청1/확인0: 광고는진행시간없어구버전의전환확인이4.5초뒤실패. 물리적넘김은성공이나전체자동재개E2E는실패로구분.
- 현재광고의 별도 '광고'라벨을 접근성으로 확인. id없음,ViewGroup,text/description정확일치,작은bounds,같은bounds의클릭가능부모,릴스pager내부. 영상제목/계정/상품문구는문서에기록하지않음.
- 추가 영상형 광고는 clips_ufi_component의 우하단 광고 배지이며 부모 터치영역이 글자보다 크다. 해당 구조를 추가해 실제 ON/OFF 비교 통과. 영상 안 CTA 카드가 있는 경우도 광고 릴스 전체를 이동하며 카드 자체는 누르지 않는다. 별도 팝업 창 자동 닫기는 미구현/범위 미확정.

## 동작 계약

- 새 skip_ads 기본OFF. 사용자가 켜야 적용. Instagram선택에종속하되해제해도값보존.
- OFF에서는 광고를 자동으로 넘기지 않으며 수동 넘김이 필요하다. 일반 N회 규칙으로 광고를 처리하는 별도 모드는 이번 범위에 없다.
- 실행ON·현재횟수1이상·Instagram선택·광고옵션ON에서만광고이동.
- 0.2.1에서는0회가광고까지전체자동넘김중지. 광고토글자체는일반영상목표횟수를바꾸지않음.
- 일반영상은기존N회완주. 광고는진행시간없이별도광고표식/구조확인후다음페이지1회요청. '광고'가캡션·작성자·웹본문에들어간것은광고판정하지않음.
- 먼저전체트리의댓글/메뉴/복수pager/미지원구조를검사. 광고발견즉시전역검사를생략하지않음.
- 광고링크/자세히보기/구매버튼은누르지않음. 정확한릴스pager의 ACTION_SCROLL_FORWARD만사용. 거절시좌표fallback없음.
- 광고는재생시간없는 recognized 페이지이고 usable영상은아님. 정상영상도시간만없다면확실한단일영상/식별정보가있는경우전환확인에만사용.
- 이동요청중추가요청금지. APItrue는성공확정이아님. 최소1.2초전환확인,4.5초미확인시정지. null/무정보/같은광고에자동재시도하지않음.
- 미확인 요청 중 드래그/구성변경/수동탐색/앱전환은 안전 정지한다. 명시적인 설정 변경은 기존 새 설정 적용 정책을 유지한다.
- 광고끼리는고정식별값을공유하므로지연된pageChanged이벤트만으로연속광고를확인하지않음. 별도구분이안되는연속광고는안전정지할수있으며모든광고100%지원으로보고하지않음.

## 수정 책임과 검증

- 설정/UI: SettingsStore,SettingsScreen,MainActivity,ids,저장소시험.
- 감지: InstagramPolicy/Reader,YouTubeSnapshot,ShortsReader 및오인식시험.
- 실행: AdSkipPolicy,AdvanceGate,ShortsAccessibilityService,전환·옵션시험.
- 실기기: 옵션OFF대기→ON광고즉시이동→일반릴스카운트,0/OFF/앱미선택,댓글/빠른설정안전,연속요청방지,CTA미클릭,YouTube회귀.
- 빌드·JUnit·lint·독립코드리뷰와실기기시험결과를분리기록. 설치본재추출해시와최종APK일치확인. 이 설계 단계의 GitHub 게시는 없음.
