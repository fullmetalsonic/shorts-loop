# 설정·플로팅·Instagram·아이콘 업데이트 계획

상태: 사용자가 0~99회/작은 X 절충안을 포함해 구현 승인. 0.2.0 구현·빌드·120개 자동시험·정적 독립 리뷰 완료. 휴대폰 업데이트 설치, 잠금 해제가 필요한 실기기 UI/자동 넘김 재시험은 대기. 최종 인앱은 [UI 설계](UI_DESIGN.md)의 하단 고정 실행 구조다. 아래 초기 제안·승인 대기 표현과 조사 근거는 당시 이력으로 보존한다.

## 사용자 요구사항

1. 반복 횟수 직접 숫자 입력과 옆의 위/아래 화살표.
2. 0은 자동 넘김 안 함이라는 설명.
3. 플로팅 탭을 0…N 순환 또는 0↔N 전환 중 선택.
4. 플로팅을 더 투명하게 하고 가로 폭을 거의 절반으로 축소. X를 모서리에 배치.
5. Instagram 릴스 지원 가능성 확인 후 YouTube/Instagram 다중 선택.
6. 플로팅 없이도 사용 가능.
7. 인앱 시작/정지 버튼을 단일 실행 토글로 통합.
8. 추가 요청: 사용자 제공 기존 앱 아이콘 사진과 같은 짙은 남색·네온·입체감. 인스타그램 실기기 조사 승인.

## 설정 화면 제안

```text
실행                         [토글]
상태: 실행 중 / 중지 / 0회로 자동 넘김 대기

기준 반복 횟수              [ 2 ] [▲▼]
0 = 자동으로 넘기지 않음
현재 적용 횟수: 2회

적용 앱               [✓] YouTube 쇼츠
                      [ ] Instagram 릴스

플로팅 표시                  [토글]
플로팅 터치 방식
  (●) 0 → 1 → … → 기준 횟수 → 0
  ( ) 0 ↔ 기준 횟수
```

- 횟수 범위는 우선 0~99 제안(사용자 최종 승인 필요). 빈칸·음수·소수·범위 초과 입력은 확정하지 않고 안내한다. 입력 중 빈칸을 0으로 저장하지 않는다.
- 위 0~99회 범위 및 작은 모서리 X는 이후 사용자가 승인했다.
- 입력 확정/화살표 변경은 기준 N과 현재 적용 M을 함께 변경하고 카운트를 새로 시작한다. 편집 중 키 입력마다 즉시 재생 설정을 바꾸지 않는다.
- 선택 앱이 없으면 켜지지 않으며 선택 안내. Instagram 미설치 시 해당 항목 비활성 및 설명.
- 두 앱을 선택해도 전면의 선택된 앱만 감지한다. 홈 피드·게시물·DM 등 릴스 이외 화면에서는 동작하지 않는다.

## 상태 계약과 기존 동작과의 차이

- 기준 N과 현재 적용 M을 분리 저장한다. N=5에서 플로팅으로 M=2를 선택해도 다음 순환의 최대값 N=5는 보존된다.
- 플로팅 분모는 실제 M이다. 예: N=5, M=2일 때 표시 1/2; 인앱에서 기준5회/현재2회로 설명.
- 순환: 0→1→…→N→0. 전환: 0↔N. N=0이면 M도0이며 인앱에서 양수로 바꾸기 전에는 자동 넘김이 시작되지 않는다.
- 실행 ON은 기준 N으로 시작. OFF는 자동 동작 중지 및 플로팅 숨김.
- M=0은 실행 제어가 켜져 있어도 자동 넘김만 대기한다. 플로팅은 남아 다시 양수로 전환 가능.
- 실행 토글과 빠른 설정 타일은 같은 실행 상태를 표시하고, 0일 때 '0회 · 자동 넘김 안 함' 상태 설명을 함께 표시한다. 기존 타일이 M=0에서 비활성으로 보이던 규칙은 이 일관된 실행 표시로 변경하는 안이다.
- X는 기존처럼 전체 종료(실행 OFF+플로팅 숨김). 플로팅 사용 설정은 보존한다.
- 플로팅 표시 OFF는 표시만 숨긴다. 실행 여부/현재 M을 바꾸거나 자동으로 새 실행을 시작하지 않는다.
- 플로팅을 사용하지 않으면 접근성만 필요하며 다른 앱 위 표시 권한을 요구하지 않는다. 표시 사용 시에만 오버레이 권한을 확인한다. 새 권한은 자동 부여하지 않는다.
- 앱 전환, 영상 전환, 적용 앱 변경 시 이전 영상의 횟수를 이어 쓰지 않는다.
- 업데이트/서비스 재연결 후 자동 실행하지 않는 기존 안전 규칙 유지.
- 마이그레이션: 기존 양수 target은 N/M으로, 기존 target=0이면 N=last_nonzero/M=0으로 이전한다. 기본 YouTube만 선택, 플로팅 사용, 순환 모드 유지.

## 플로팅 디자인 제안과 제약

- 현재124dp 폭을 약64~72dp로 축소하는 시안. X의 별도 옆 열을 없애고 모서리 배치. 정확한 크기는 99/99 및 큰 글꼴 실기기 확인 후 결정.
- 배경 불투명도는 약40%로 낮추고 숫자는 더 선명하게 유지한다. 기존 전체창72% 방식과 구분.
- 숫자 터치/드래그 영역은 크게 유지하고, X만 작은 모서리 버튼으로 만드는 절충을 제안한다.
- 기존처럼 숫자와 X 모두 독립48×48dp 영역을 유지하면서124×56dp를62×56dp로 줄이는 것은 불가능하다. X 영역 축소는 접근성 목표 완화이므로 사용자 승인 필요. 보이지 않는 영역을 바깥에 늘려 실제 터치 가로채기 폭을 감추지 않는다.
- [Android 공식 터치 영역 권고](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views?hl=en): 적어도48×48dp 권장. 인앱/타일을 대체 종료 수단으로 유지하고 실제 오조작을 확인한다.
- 드래그 위치 상대 저장, 화면 경계 제한, 드래그 후 탭으로 오인하지 않는 동작 유지.
- 최종 구현값은72×56dp. 숫자48×56dp, 모서리X24×24dp. 배경alpha128/255×창alpha0.8로 약40% 불투명도, 숫자80% 불투명도. X터치영역 축소는 승인된 예외이며 실기기 오조작 검사 전이다.

## Instagram 조사 결과와 지원 범위

- Fold8/Android17, Instagram444.0.0.46.85에서 릴스 화면을 직접 확인했다.
- clips_viewer_view_pager와 clips_video_container, SeekBar인 id/scrubber 확인. RangeInfo가 전체 길이/현재 위치를 숫자로 제공한다.
- 19.014초 영상의 연속136개 정상 표본에서 끝→처음 경계3회 관측. 18.708→0.095초, 18.705→0.083초, 18.737→0.124초. 경계 간격402~403ms, 숫자 진행392~401ms로 밀리초 해석을 뒷받침한다.
- ADB로 영상 내부에서 아래→위 스와이프1회 후 다른22.638초 릴스가 열린 것을 화면과 진행값으로 확인. 두 번째 영상에서도22.377→0.147초 경계 확인.
- 첫 일시정지 상태에서18.721초 고정 후 재개 시 시간 진행 확인.
- 위는 개발용 진단 관측이다. 우리 앱의 정확한 N회 카운트/자동 넘김 성공 증거가 아니며, Instagram 지원은 구현 가능한 근거를 확보한 상태다.
- [조사 프로브 실행·해석 지침](../scripts/probes/README.md). 조사 종료 후 Instagram은 재생 상태로 복귀시키고 ShortsLoop 실행OFF/기존 설정 보존을 확인했다.
- [Laze 소스](https://github.com/perkompus/Laze/blob/main/app/src/main/java/com/perkompus/laze/LazeService.kt)는 Instagram 패키지와 RangeInfo 사용 예시이지만 임의 range의95%에서 넘기는 단순 방식이다. 정확한 완주/N회·릴스 외 화면 차단을 충족하지 않아 복사/설치하지 않았다.
- 구현 시 앱별 감지기와 공통 반복기를 분리한다. 조회 전 선택된 패키지 확인, 릴스 컨테이너/가시성/단일 진행막대/입력초점 검사, 갱신 실패 시 대기, 앱별 영상 구분이 필요하다.
- Instagram 광고·사진/혼합 콘텐츠·진행값 미노출 영상은 일반 릴스와 같다고 가정하지 않는다. 시간 추정으로 강제 넘기지 않고 감지 불가 시 대기한다.
- 다른 창/댓글/메뉴/일시정지/탐색·수동 넘김의 보호는 서비스 통합 후 별도 검증한다.

## 수정 영역과 검증 계획

1. core ModePolicy/LoopCounter, data SettingsStore: N/M, 모드, 적용 앱, 표시 옵션, 기존값 이전. 범위·입력·0·상한·이전 단위시험.
2. native 설정 UI/overlay/service/tile: 통합 토글, 두 탭 모드, 표시-권한 분리, 컴팩트 플로팅. 기존 위치·드래그·X·타일 회귀시험.
3. detection: YouTube 동작 유지, Instagram 전용 감지기/앱 라우터, 패키지를 포함한 영상 구분 및 공통 창 보호.
4. 앱 아이콘 adaptive/legacy/단색 자산 적용 후 실제 런처 확인.
5. build/lint/JVM시험 → 설치APK해시 확인 → 두 앱 각각 N=1/2/3, 0, 두 탭 모드, 단독/둘 선택/선택제외 앱, 플로팅 OFF+오버레이 권한 없이 실행, 재시작/위치 보존, 정지/댓글/빠른 설정 보호 검증.
6. 독립 코드·요구사항·증거 리뷰 후 문서 버전/누적이력/디버그 대장 갱신. 관측용 UIAutomator와 제품 E2E는 동시 실행하지 않는다.
