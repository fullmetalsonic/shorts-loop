## 주요 변경 / Changes

- **긴 영상 건너뛰기:** 기본OFF,총길이 기준60초,숫자 입력·±로1~3600초 설정. 확인된 영상 길이가 기준 이상이면 안전한 재생 진행 확인 후 넘깁니다. 반복0과 독립이며 전체OFF는 중지합니다.<br>
  **Long-video skipping:** OFF by default,60-second total-duration threshold,1–3600 seconds via typing/±. Qualifying known durations advance after safe playback checks,independently of zero repeats;overallOFF stops it.
- **일반 카운트 복구:** 일반 영상 넘김 확인 시간초과 시 추가 스와이프 없이 새 재생 시작을 관측하고 설정 횟수를 처음부터 다시 셉니다. 광고·라이브·시간제·긴 영상 실패는 이 복구로 우회하지 않습니다.<br>
  **Fresh-start recovery:** after an ordinary confirmation timeout,observe a verified new beginning and recount full plays without a retry swipe. Special-content and long-video failures do not use this recovery.
- **YouTube 전환 확인 보강:** 같은 창·pager·전체 페이지의 현재 행이 요청 행보다 정확히1 증가한 근거를 추가합니다. 다른 콘텐츠 키·안정·실제 전진 검사는 유지하며,알려진 동일/역방향/건너뛴 행은 거절합니다. 이번 code26→code28 YouTube 보완에서 Instagram과 공용 확인 정책은 code26 그대로 유지했습니다.<br>
  **YouTube confirmation:** adds exact current-row=request-row+1 evidence,retaining same-window/pager/full-page,changed-content,stability and forward-playback guards. Known unchanged/backward/skipped rows reject. Instagram and shared confirmation policy are unchanged from code26 for this code26→code28 YouTube correction.
- 긴 영상 카드는 일반 횟수 바로 아래에 배치하고,복구 대기·안전정지와0회 독립 옵션을 구분해 표시합니다. 원본 출처 표시 요청을 한영README에 추가했습니다.<br>
  The long-video card follows repeat settings;waiting/stopped and zero-repeat options are distinguished. The bilingual README now requests original-source attribution.

## 사용·업데이트 / Use and update

긴 영상의60초는 **대기 시간이 아니라 영상 전체 길이 기준**입니다. 총길이를 모르면 추측하지 않으며,지원되는 진행정보 없는 Instagram 영상은 기존 선택형10초 시간제를 따릅니다. 반복0은 일반 반복·시간제를 중지하지만 긴 영상·광고·라이브 옵션은 각각 독립입니다. 모든 자동 넘김을 끄려면 전체 실행을OFF로 합니다.<br>
The60-second long-video value is a **total-duration threshold,not a wait**. Unknown duration is not guessed;eligible clockless Instagram videos retain the optional ten-second fallback. Zero repeats stops normal/timed advancing,while long-video,ad and live options remain independent. OverallOFF stops all automation.

기존 앱을 삭제하지 않고 같은 서명의 APK로 업데이트하면 설정을 보존합니다. 설치·접근성·출처 권한은 Android 안내에서 직접 확인하며,업데이트 후 실행을 자동으로 켜지 않습니다. [상세 사용 설명서](https://github.com/fullmetalsonic/shorts-loop/blob/main/docs/USER_GUIDE.md).<br>
Update over the existing same-signer installation to preserve settings. Android installation/accessibility/source permissions require manual confirmation;execution is not automatically restarted. See the linked guide.
