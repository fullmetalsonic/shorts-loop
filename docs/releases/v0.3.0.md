- YouTube/Instagram의 반복·긴영상·탭 방식·플로팅 위치·일시정지를 분리했다. YT/IG 플로팅의 X는 해당 앱만 정지하며 전체OFF는 모두 정지한다. / Independent host settings and floats;X pauses that host,overallOFF stops all.
- 기존 키를 유지하고 앱별 초기값을 한 번만 복사한다. 초점·재생을 강제로 바꾸지 않으며 제스처는 직렬화하고 직전에 창·콘텐츠·입력 경로를 재검사한다. / Preserves legacy settings with one-time host migration;no forced focus/playback and serialized,revalidated input.
- 분할 경계·회전 상태표시줄·전체화면 SystemUI 손잡이의 오인을 제한적으로 수정했다. 일반 팝업·키보드·입력 충돌 보호는 유지한다. / Scoped system-chrome detection fixes preserve popup,keyboard and touch-corridor protection.
- 한국어/영어 UI·사용법·검증/디버그 문서를 갱신했다. / Updated Korean/English UI and documentation.
