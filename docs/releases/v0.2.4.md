## 변경 / Changes

- **진행 정보 없는 Instagram 영상만 선택형 시간제.** 기본 OFF·10초, 숫자 입력·완료/적용 또는 −/+로 1초씩 조절, 범위 5~60초. 정상 진행 정보가 있으면 기존 N회가 우선이며 YouTube 동작은 바꾸지 않습니다. 반복 2회·시간 10초라면 일반 영상은 2회, 정보 없는 대상은 총 10초입니다. 완주 횟수나 영상 길이를 알아내는 기능이 아닙니다.
  **Optional timed fallback for clockless Instagram videos.** OFF by default, initially 10 seconds, adjustable 5–60 with typing/Done/Apply and one-second −/+ controls. A usable clock keeps N-play counting; YouTube is unchanged. With 2 plays/10 seconds, normal videos use 2 plays and eligible clockless videos wait 10 seconds total. This does not infer duration or completion.
- **광고는 반복 횟수와 독립.** Instagram 선택 + 광고 옵션 ON + 전체 실행 ON이면 0회에서도 인식한 광고를 넘깁니다. 일반 영상·시간제는 0회에서 중지합니다. 전체 실행 OFF는 광고까지 모두 중지합니다. 광고 옵션 기본값은 계속 OFF입니다.
  **Ad skipping is independent of repeat count.** Instagram selected + ad option ON + main execution ON allows recognized ads to advance even at zero plays. Normal and timed advancing stop at zero. Main execution OFF stops everything. The ad option remains OFF by default.
- **기능별 설정 분류.** 사용할 앱 / 일반 영상·횟수 / 진행 정보 없는 영상·시간제 / 광고 / 플로팅 / 사용 준비 / 실험 기능을 분리합니다. 하단 메인 토글은 ‘전체 자동 넘김 실행’입니다. 광고만 쓰는 설정은 반복 0회 + 광고 ON + 전체 실행 ON입니다.
  **Settings grouped by function.** Target apps, normal repeats, clockless timing, ads, floating controls, setup and experiments are separate. The fixed footer is the main execution toggle. For ads only, choose zero plays, ads ON and main execution ON.
- **기존 화면 분석 시험 기능 보존.** 기본 OFF·별도 동의·Android 14 이상·RAM 전용입니다. 시간제와 함께 켜면 시간제가 우선하고 화면 분석 선택값은 보존합니다. 학습으로 추가 재생될 수 있어 정확한 총 N회를 보장하지 않습니다.
  **Existing visual assist preserved.** Default-off, separately consented, Android 14+ and RAM-only. Timed fallback takes priority while preserving the visual preference. Learning may add plays; exact total N is not guaranteed.

## 사용 예와 주의 / Examples and cautions

| 설정 / Settings | 동작 / Behavior |
|---|---|
| 반복 2회·시간제 10초·전체 ON / 2 plays, 10-second fallback, main ON | 정상은 2회, 정보 없는 지원 영상은 총 10초 / Normal: 2 plays; eligible clockless: 10 seconds total |
| 반복 0회·광고 ON·Instagram 선택·전체 ON / Zero, ads ON, Instagram selected, main ON | 일반·시간제 중지, 인식된 광고만 넘김 / Normal and timer stopped; recognized ads only |
| 반복 0회·광고 OFF·전체 ON / Zero, ads OFF, main ON | 넘김 없이 제어만 켜짐 / Control enabled, no advancing |
| 전체 OFF 또는 플로팅 × / Main OFF or floating × | 광고 포함 모두 중지 / Everything stopped, including ads |

- 시간 값은 반복 횟수와 독립 저장되지만 시간제 실행은 현재 횟수 1 이상이 필요합니다. 빈칸·부호·소수·5 미만·60 초과는 저장하지 않습니다.
  Seconds are saved independently, but timed execution requires a positive current repeat target. Empty, signed, fractional and out-of-range values are rejected.
- 정상 영상의 다음 처음 재생 대기 `0/N`을 시간제로 바꾸지 않습니다. 감지된 정지·댓글·메뉴·잠금·앱/창 전환 등은 타이머를 초기화하고 복귀 후 처음부터 기다립니다. 시간제는 완주 전에 넘기거나 여러 재생을 기다릴 수 있습니다.
  Normal `0/N` waiting for a new playback cycle does not become timed fallback. Detected pauses, comments, menus, locking and app/window changes reset the wait. Timing may end before completion or after multiple plays.
- 광고는 명시적인 광고 구조를 확인한 경우만 처리합니다. 재생바 없음·`#광고` 캡션만으로 광고라고 판단하지 않습니다. 광고 CTA·구매 버튼은 누르지 않고 릴스 다음 페이지 동작만 요청합니다. 별도 팝업 자동 닫기와 YouTube 광고는 지원하지 않습니다.
  Ads require explicit recognized ad structure, not just a missing seekbar or `#ad` caption. The app requests the next Reel page without clicking CTAs or purchase links. Separate-popup closing and YouTube ads are unsupported.
- 업데이트 전 광고 옵션이 ON이었다면 새 버전에서 반복 0회여도 광고가 넘어갈 수 있습니다. 광고를 원치 않으면 광고 옵션을 끄세요. 기존 저장값을 임의로 초기화하지 않습니다.
  If ads were already ON before updating, they may now advance at zero plays. Turn the ad option OFF if unwanted. Existing saved preferences are not silently reset.
