- 사용 준비에 배터리 절전 예외 상태·수동 설정 안내·이 앱의 설정 바로가기 추가. 돌아오면 상태 갱신.
  Added battery-exemption status, manual instructions, and an own-app settings shortcut, refreshed on return.
- 새 권한·자동 절전 설정 변경·자동 실행 재시작 없음. 기존 횟수·플로팅·앱 선택·광고 기능 유지.
  No new permissions, automatic system-policy changes, or automatic execution restart. Existing count, floating, app-selection, and ad options remain.
- 한영 README 사용 안내와 알려진 문제, CI 및 공개 제외 규칙 정리.
  Added bilingual usage instructions, known issues, CI, and publication exclusions.

## 미해결 / Still open

YouTube의 간헐적 넘김 확인 실패와18초 영상16→0 경계 누락이 남아 있습니다. 배터리 설정으로 모든 문제가 해결된 버전이 아닙니다. 작은 창/PiP 자동 넘김은 지원하지 않습니다. 정지 시 현재 화면 확인 후 실행 OFF→ON. 반복 실패하면 실행을 끄고 수동으로 사용하세요.

Intermittent unconfirmed YouTube transitions and the18-second/16→0 loop-boundary issue remain. Battery setup does not fix every stop. PiP auto-advance is unsupported. Check the screen and toggle execution OFF→ON after a stop; use manual advancing if failures recur.
