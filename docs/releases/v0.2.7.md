# ShortsLoop 0.2.7 / code29

정식 릴리스 준비: 로컬·기기 검증 완료, GitHub 검사·공개 다운로드 검증 진행 중입니다. 시험판 표시 없이 최신 정식 버전으로 배포합니다.<br>
Stable release preparation: local/device checks are complete; GitHub CI and public-download verification are pending. This release will not be marked as a pre-release.

## 변경 / Changes

- **작은 플로팅 글자 잘림 수정:** 외곽72×56dp를 유지하면서 ‘긴영상’, ‘라이브’, 최대 횟수 등이 실제 폭에 맞게 표시됩니다. X 아래 공간을 활용하고, 글자를 축약하지 않고 가장 큰 맞춤 크기로 조절합니다.<br>
  **Compact-label clipping fix:** preserve the72×56dp overlay while fitting long labels and counts to its real width,using the space below X without abbreviating labels.
- 탭으로 횟수 변경,끌어서 위치 고정,X로 종료,반투명 디자인은 유지합니다. 감지·카운트·자동 넘김 정책은0.2.6에서 변경하지 않았습니다.<br>
  Tap-to-cycle,drag-to-position,X-to-stop and transparency remain. Detection,counting and auto-advance policies are unchanged from0.2.6.
- 실제 글자 경계·큰 글꼴·굵은 글꼴·RTL 배치·상태 전환 검사를 추가해 잘림 재발을 탐지합니다.<br>
  Actual text-boundary,large-font,bold,RTL-layout and state-transition checks now detect clipping regressions.

## 설치·업데이트 / Installation and update

Android8.0(API26) 이상. 첨부 APK를 기존 앱 위에 설치하면 설정을 보존합니다. 인앱 **업데이트 · 앱 정보 → 업데이트 확인**으로도 확인할 수 있습니다. 설치 출처 허용과 최종 설치는 Android 안내에서 직접 확인합니다. 설치 전 전체 실행을 끄고,설치 후 사용할 때 직접 켜 주세요.<br>
Android8.0(API26)+. Install the attached APK over the existing app to preserve settings,or check under the in-app update section. Source permission and final installation require manual Android confirmation. Stop execution before updating and enable it manually when ready afterward.

접근성 설정이 켜져 있어도 연결이 안 됐다면 앱의 연결 안내를 확인하고 필요할 때 서비스를 OFF→ON 해 주세요. 새 권한이나 무인 자동 설치를 추가하지 않았습니다.<br>
If accessibility is enabled but disconnected,follow the app's reconnect instructions and toggle the service OFF→ON if needed. No new permissions or silent installation are added.
