## 업데이트·보안 / Upgrade and privacy

0.3.0/code32에서 같은 패키지·서명으로 덮어 설치한다. 기존 설정키/자료형은 보존하며host schema v2는TikTok의 보수적 기본값만 추가한다. 실행은 설치 전에OFF로 두며 권한·설치 최종 승인은 직접 한다. 새 권한·콘텐츠 수집·추가 네트워크 전송은 없다. 원시 기기 로그·개인 화면·기기 식별자·서명 키는 공개하지 않는다.
