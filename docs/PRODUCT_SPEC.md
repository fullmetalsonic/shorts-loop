# 제품 기준 · ShortsLoop 0.2.4

최신 계약은 **일반 영상의 N회 반복 / 진행 정보 없는 Instagram의 선택형 시간제 / 반복 횟수와 독립된 Instagram 광고 넘김**을 구분한다. 시간제 기본 OFF·10초·5~60초·±1초이며 정상 진행 정보와 YouTube는 기존 N회를 유지한다. **현재 0회는 일반·시간제 중지, 광고는 별도 옵션에 따름. 전체 실행 OFF는 모두 중지**한다. 과거 0.2.1의 ‘0회 광고 중지’는 아래 역사적 시험에만 적용한다.

이 문서는 동작 계약이며 시험 완료 선언이 아니다. 사용자는 정상·시간제·광고 합계 20연속 확인이 끝나기 전에 현재 시험판 공개를 승인했다. 20연속 검증은 미완료로 남기며 후보별 결과를 합산하지 않는다. 최종 빌드·시험·기기·독립 리뷰·공개 결과는 [VERIFICATION](VERIFICATION.md)과 [0.2.4 릴리스](releases/v0.2.4.md)를 기준으로 한다. [사용 설명서](USER_GUIDE.md), [UI·인간공학 기준](UI_DESIGN.md), [시간제 계약](TIMED_FALLBACK.md), [최초 조사](UPDATE_PLAN_2026-08-27.md), [과거 광고 승인 설계](ADS_PLAN_2026-08-27.md)를 함께 관리한다.

0.2.2의 배터리 계약도 유지한다. 자기 앱의 Android 절전 예외 상태를 읽고 안내 후 자기 앱 상세 설정만 연다. 사용자가 배터리 → 제한 없음을 직접 선택하며 시스템 정책 자동 변경·새 권한·실행 자동 재시작은 없다. Activity 복귀 시 재조회하고 실패는 ‘확인 불가’/수동 안내로 처리한다. 예외 미적용 자체가 실행을 차단하지 않으며 모든 절전 정책·PiP·안정성을 보증하지 않는다.

## 1. 대상과 승인 범위

일반 YouTube 앱의 쇼츠 및 Instagram 앱의 지원되는 단일 동영상 릴스를 처음부터 설정 횟수만큼 관측한 뒤 다음 영상으로 이동한다. 사용자는 YouTube Premium을 사용한다고 설명했다. 0.2.1은 별도 승인에 따라 인식된 Instagram 광고의 다음 페이지 이동을 선택 제공한다. 광고 제거/네트워크 차단·YouTube 광고 처리·타사 앱 개조·외부 네트워크 전송은 범위 밖이다.

사용자가 승인한 0.2.0 변경은 다음과 같다.

- 기준 횟수 0~99, 숫자 직접 입력과 위/아래 화살표.
- 당시 0의 의미를 ‘자동 넘김 안 함’으로 명시. 최신 0.2.4에서는 광고 독립 동작 예외를 추가한다.
- 기준까지 순환 또는 0↔기준 전환의 두 플로팅 터치 방식.
- YouTube/Instagram 다중 선택 및 플로팅 표시 선택.
- 인앱 실행 토글 하나와 빠른 설정 연동.
- 플로팅 폭 축소와 투명도 증가, 작은 모서리 X 예외.
- 제공된 앱 아이콘 사진과 일체감 있는 남색·청색·보라색 계열 및 직관적인 인앱 구성.

0.2.1 추가 승인: Instagram 광고임을 확인하면 완주를 기다리지 않고 다음 페이지로 이동하며 별도 ON/OFF·기본 OFF를 제공했다. 당시 재생바 없는 일반 릴스는 수동 대기였다.

0.2.4 후속 승인: 진행 정보를 읽지 못하는 안전한 단일 Instagram 영상에 선택형 시간제를 제공한다. 최초 후보 A의 15초/5~120초는 역사이며 후보 B와 공개판은 **10초/5~60초**다. 광고는 반복 횟수와 독립하여 0회에서도 사용할 수 있고 UI를 기능별 카드로 나눈다. 재생바 없음 자체를 광고로 간주하거나 사진·혼합·불명확 화면을 시간제로 넘기는 것은 여전히 범위 밖이다.

## 2. 상태와 용어

| 값 | 의미·범위 |
|---|---|
| 기준 N | 인앱에서 확정한 총 재생 횟수, 0~99 |
| 현재 M | 실제 영상에 적용하는 횟수, 0~N |
| 현재 회차 C | 완주를 추적 중인 회차, 0~M |
| 실행 E | 실행 제어 ON/OFF. M=0과 구분 |
| 플로팅 F | 표시 사용 설정. 실행 여부와 독립 |
| 터치 방식 | ROTARY=0: 0…N 순환 / TOGGLE=1: 0↔N |
| 적용 앱 | YouTube·Instagram 각각 선택, 기본 YouTube만 |
| 광고 옵션 A | `skip_ads` ON/OFF, 기본 OFF. Instagram에만 적용 |
| 시간제 T | `timed_fallback` ON/OFF, 기본 OFF. 진행 정보 없는 지원 Instagram 영상만 |
| 대기 시간 S | `fallback_seconds`, 기본 10초·정수 5~60초. 횟수와 별도 저장 |
| 화면 분석 V | `visual_assist` ON/OFF, 기본 OFF·별도 동의·Android 14 이상 시험 기능 |

정상 추적의 플로팅은 C/M을 표시한다. N=5, M=2이면 `1/2`·`2/2`이며 기준 5는 보존한다. 시간제 중에는 `10초 → 9초` 등 남은 시간, 이동 확인 중에는 해당 상태를 표시한다. M=0에서 Instagram 선택/A=ON이면 ‘광고’를 표시하여 일반 영상 정지와 광고 대기를 구분한다. 화면 분석의 `…/N`·`~n/N`은 학습/추정이며 확정 완주가 아니다.

0은 실행 전체 종료가 아니라 **일반 영상 반복·시간제 중지** 값이다. E=ON/M=0에서도 Instagram 선택/A=ON이면 광고를 넘길 수 있다. 하단은 ‘광고만 넘김 / 일반·시간제 중지’ 또는 ‘일반·시간제 중지 / 광고 꺼짐’을 구분한다. E=OFF이면 광고까지 중지하고 플로팅도 닫는다. **광고 전용 사용 = M=0 + Instagram 선택 + A=ON + E=ON**이다.

## 3. 입력·실행 전이 계약

| 조작 | 저장과 실행 결과 |
|---|---|
| 숫자 타이핑 | 임시 입력. 저장값·진행 설정 즉시 변경 안 함 |
| 완료/적용 | 0~99 정수만 N/M에 함께 저장, 횟수 초기화 |
| ▲/▼ | 유효한 입력에서 ±1 후 0~99 범위로 즉시 적용 |
| 잘못된 입력 | 적용 차단·설명. 빈칸을 0으로 저장하지 않음 |
| 인앱 실행 ON | 횟수 초안 검증 후 M=N, E=ON. N>0/T=ON/Instagram 선택일 때만 초 초안도 검증. 앱 선택·설치·권한 확인 |
| 빠른 설정 ON | M=N, E=ON. 접근성·앱 선택·필요한 표시 권한 확인 |
| 실행 OFF/타일 OFF/X | E=OFF, 플로팅 닫기. N/M/F/위치 보존 |
| ROTARY 숫자 탭 | M<N이면 M+1, M=N이면0. N 보존 |
| TOGGLE 숫자 탭 | M=0이면 N, M>0이면0. N 보존 |
| 터치 방식 변경 | 방식 저장, M=N으로 맞춤, 횟수 초기화 |
| F OFF | 표시만 숨김. E/M/진행 추적 자체는 유지 |
| F ON | 실행 중이면 권한 확인 후 표시. 권한 없으면 안전 정지 |
| 앱 선택 변경 | 이전 추적 초기화. 전부 해제하면 실행 중지 |
| 광고 옵션 변경 | A만 저장. N/M/E를 변경하거나 실행을 새로 켜지 않음 |
| 시간제 ON | Instagram 선택 및 초 초안 검증 후 T만 저장. N/M/E 변경 없음 |
| 초 완료/적용 또는 −/+ | 5~60 정수만 S에 저장. −/+는 1초씩. 횟수와 별도 저장 |
| 시간제 OFF | T만 끄고 S/V 보존. 선택된 기존 화면 분석 경로가 사용될 수 있음 |
| 화면 분석 ON | Android 14 이상·Instagram 선택 때 안내 확인 후 V=true. 취소는 OFF 유지 |
| Instagram 선택 해제 | 광고·시간제·화면 분석 조작 비활성. A/T/S/V 저장값 보존, Instagram 동작 금지 |
| 숫자 드래그 | 횟수 추적 보류/초기화, 상대 위치 저장. 탭으로 오인하지 않음 |

N=0이면 M도0이며 실행 ON이나 플로팅 탭이 과거 양수 설정을 복원하지 않는다. 플로팅 표시 OFF는 카운트를 초기화하는 설정이 아니지만, 설정 앱으로 전환하는 행위 자체는 대상 영상 앱을 벗어나므로 앱 전환 보호가 적용된다.

잘못된 저장값은 순수 정책으로 정규화한다. 정상 입력 UI에서는 잘못된 숫자를 임의 기본값으로 확정하지 않고 오류를 보여 준다. 기준 N과 현재 M 등 함께 변경되는 값은 SharedPreferences의 한 Editor로 갱신한다.

## 4. 감지와 자동 넘김

- 선택된 앱 패키지와 포커스를 확인한 다음 해당 앱 전용 감지기를 호출한다. 두 앱이 선택되어도 현재 앞에 있는 앱만 대상이다.
- YouTube는 쇼츠 컨테이너와 단일 진행막대의 최신 시간을 확인한다.
- Instagram은 릴스 pager 내부의 단일 영상 컨테이너, 단일 media, `scrubber` 진행막대와 유효한 밀리초 범위를 확인한다.
- 일반 Instagram 릴스의 사진/혼합 콘텐츠, 댓글/메뉴 또는 영상 식별 정보 부족을 감지하면 대기한다. 정상 진행 정보를 읽으면 기존 횟수, 진행 정보 없는 지원 단일 영상이면 선택한 시간제/화면 분석 경로를 적용한다. 별도로 확인된 광고만 광고 계약을 적용한다. 모든 광고·메뉴 유형의 판별을 보장하지 않는다.
- 앱 패키지를 포함한 식별값으로 영상과 앱을 구분한다. 앱 전환 때 진행 상태를 초기화하여 다른 앱의 카운트를 이어 쓰지 않는다.
- 정상 진행 정보는 약 300ms 간격으로 관측하고 영상 끝→처음 이동·관측 진행량·최소 경과시간을 확인한다. 이 N회 경로를 단순 시간 타이머로 대체하지 않는다.
- 중간에 켜면 현재 부분 재생은 완주로 세지 않는다. 다음 시작까지 C=0, 추적 중 C=1…M이다.
- 정상 횟수 경로의 자동 제스처는 영상 영역 높이 75%에서25%까지 아래→위로 이동한다. 플로팅 영역과 시스템 모서리를 피한다. Instagram 시간제와 광고는 정확히 식별한 pager 동작을 사용한다.
- 스와이프 요청 성공과 다음 영상 전환 성공을 구분한다. 전환이 확인되지 않으면 연속 재시도하지 않고 재시작 안내 상태로 멈춘다.

### Instagram 광고 즉시 넘김 계약

- E=ON, Instagram 선택, A=ON을 모두 만족하고 전면의 Instagram 릴스에서 광고 근거와 안전한 화면 구조를 확인해야 한다. **M>0은 광고 조건이 아니며 M=0에서도 광고만 넘길 수 있다.**
- 기본 A=OFF이다. E=OFF 또는 A=OFF는 광고를 중지한다. A 변경은 N/M/E를 바꾸지 않는다. 업데이트 전 A=ON이었다면 새 0회 동작에 영향을 주므로 설명서에서 확인을 안내한다.
- 광고 라벨·컨테이너 구조를 검사한다. 캡션·작성자·본문에 ‘광고’라는 단어가 있거나 재생바가 없다는 이유만으로 광고로 간주하지 않는다.
- 실측된 우하단 동영상 광고 배지는 `clips_ufi_component` 내부의 작은 라벨이고 클릭 가능한 부모 영역이 라벨보다 클 수 있다. 해당 구조·위치·라벨의 정확한 일치를 함께 검사한다. 일반 캡션의 `#광고`만으로 이 구조를 대체하지 않는다.
- 광고를 발견해도 전체 화면의 댓글/메뉴/복수 pager/지원하지 않는 구조 검사를 생략하지 않는다.
- 새로 조회한 정확한 릴스 pager에 `ACTION_SCROLL_FORWARD`를1회 요청한다. 광고 링크·CTA·구매 버튼에 클릭 동작을 보내지 않으며 거절 시 좌표 스와이프로 대체하지 않는다.
- 릴스 영상 위의 ‘더 알아보기’ CTA 카드가 있는 광고는 페이지 전체 넘김 대상이다. 별도 창 팝업의 X를 찾아 닫는 기능은 미구현이며 범위 미확정이다.
- 광고는 진행시간 없이 구조로 인식한 페이지이다. 시간값이 없지만 확실한 단일 영상·식별정보가 있는 일반 영상은 전환 확인에 사용할 수 있다. 다음 이동 여부는 별도의 T/M/안전 조건으로 판단하며 ‘직전 광고에서 넘어왔다’는 사실만으로 다시 넘기지 않는다.
- 요청 중에는 추가 요청을 금지한다. API가true를 반환했다고 성공으로 확정하지 않는다. 최소1.2초 이후 다른 페이지를 확인하며4.5초까지 확인되지 않으면 안전 정지한다.
- 광고끼리 고정 식별값을 공유하므로 늦은 페이지 이동 이벤트만으로 연속 광고를 성공 처리하지 않는다. 다른 광고임을 구분할 수 없으면 실제로 이동했어도 안전 정지할 수 있다. 같은 광고·무정보·null 상태에서 무한 재시도하지 않는다.
- 이동 확인 pending 도중 화면 구성 변경·드래그 등 세션 중단은 단순 gate 취소로 새 요청을 허용하지 않는다. `interruptSession`을 통해 확인 중이면 안전 정지하고, 확인 중이 아니면 정상 초기화한다. 독립 검토에서 지적한 중복 광고 요청 위험에 대한 보완이다.

시각은 상태 관측시각이며 첫 pending 표본을 실제 요청 시작시각으로 간주하지 않는다. 당시 N=0에서는 앱/시간 조회를 중단했으므로 진단에 남은 앱·재생시간만으로 현재 화면을 판정하지 않고 실제 화면 확인과 함께 평가했다. 광고 CTA 카드를 클릭하지 않고 pager 동작으로 전체 광고를 넘긴 것을 확인했다. 최신 버전은 0회 광고 관측을 별도로 허용하므로 이 과거 조회 규칙을 현재 계약으로 적용하지 않는다.

v021b의145개 시험 이후 독립 검토의 pending 중단 위험을 보완했다. 최종v021c 빌드·직접JUnit148·정적연결검사·독립 재리뷰 PASS, 설치본 해시 일치. YouTube43초→5초→43초 N1, 빠른 설정 타일 OFF/ON, Instagram 미선택 대기는 실제 PASS. pending 순간 회전·드래그와 장시간/모든 광고형태는 아직 실기기 완료가 아니다. 상세 범위는 검증 문서에 기록한다.

### Instagram 진행 정보 없는 영상의 시간제 계약

- E=ON/M>0/Instagram 선택/T=ON이고, 전면의 안전한 단일 동영상·식별정보·진행 정보 없음·일시정지 아님을 확인해야 시작한다. 기본 T=OFF/S=10초, 정수 5~60초이며 ±1초로 조절한다.
- 정상 진행 정보가 있으면 N회 경로가 우선이다. 중간부터 켜서 다음 처음 재생을 기다리는 C=0/M>0을 정보 없음으로 취급하지 않는다. YouTube는 시간제 대상이 아니다.
- S는 총 대기 시간이다. M=2/S=10이면 정상 영상은 총 2회, 정보 없는 대상은 총 10초이며 20초로 곱하지 않는다. 초 값 저장은 M과 독립이지만 **M=0에서는 시간제 중지**다.
- 첫 안전 관측부터 시간을 세며 같은 화면 확인 구간도 S에 포함한다. 새 영상·설정 변경·창 크기 변경·시간 역행·긴 조회 공백은 초기화한다. 1.5초 초과 조회 공백을 누적해 복귀 즉시 넘기지 않는다.
- 감지된 일시정지·댓글·메뉴·잠금·앱/창 전환·플로팅 조작·E=OFF/M=0/Instagram 해제는 타이머를 취소한다. 안전한 시청 상태 복귀 후 처음부터 센다. 모든 앱 UI·정지를 감지한다고 보장하지 않는다.
- 사진·혼합·식별 불가 화면과 광고는 타이머로 우회하지 않는다. 시간이 되면 해당 릴스 pager에 `ACTION_SCROLL_FORWARD` 한 번을 요청하고 다른 영상 식별정보를 확인해야 성공이다. 같은 영상에 시간 정보만 생긴 것은 이동 성공이 아니다. 실패는 안전 정지하고 무한 재시도하지 않는다.
- 영상 길이·완주·정확 N회를 알아내는 기능이 아니다. 긴 영상은 완주 전, 짧은 영상은 여러 재생 후 이동할 수 있다. 새 캡처·마이크·오디오 권한 없이 기존 접근성 정보로 동작한다.

### 화면 분석 및 미연결 실험의 경계

기존 화면 분석 보조 V는 기본 OFF·Android 14 이상·Instagram 선택·별도 사용자 확인 후 RAM에서만 화면 반복을 비교하는 시험 기능이다. 학습에 추가 재생이 필요하며 `~n/N`은 추정이다. 정확한 총 N회를 보장하지 않는다. T와 V가 모두 ON이면 시간제가 우선하며 새 화면 분석을 하지 않고 V 선택값은 보존한다.

미연결 `VisualSequenceTracker` 전체 구간 비교 실험은 위의 선택형 보조와 다르다. 실험 20개 중 18 PASS/2 FAIL(주기 오추정·학습 실패)을 보존하고 배포 앱/제품 시험의 sourceSets에서 제외한다. 제품 시험 PASS를 미연결 실험까지 포함한 전체 PASS로 표현하지 않는다. 별도 [오디오 수신](AUDIO_PROBE_TRIAL.md)·[음향 패턴](AUDIO_PATTERN_TRIAL.md) 진단 앱은 제품 자동 넘김에 연결하지 않으며 이번 제품 APK 첨부 대상이 아니다.

## 5. 안전·정확도 제한

- 선택 앱의 지원 화면, 각 경로의 진행 정보/시간제 구조/입증된 광고 조건, 화면 켜짐/잠금 해제, 입력초점 조건을 만족할 때만 자동 동작한다.
- 댓글·키보드·메뉴·앱 전환·드래그·영상 변경·긴 관측 공백·수동 탐색으로 판단한 점프는 보수적으로 추적을 초기화한다.
- 정상 진행 영상의 일시정지·버퍼링 동안 시간 경과만으로 넘기지 않는다. 시간제는 감지된 중단에 한해 취소하므로 완주를 보장하지 않는다. 광고는 완주 및 M과 독립이지만 E=OFF에서는 멈춘다.
- 현재값 변경·X·OFF는 이전 추적/예약 동작보다 우선한다. 플로팅 표시 변경은 별도 표시 경로이다.
- 프로세스나 접근성 서비스가 다시 연결되면 자동 실행하지 않고 E=OFF로 시작한다.
- 빠른 설정창·다른 포커스 창·PiP에서는 대기한다. 다른 앱의 비포커스 플로팅이나 팝업 가림을 전부 판별한다고 보장하지 않는다.
- 0.1.4의 최신 접근성 시간 갱신·양자화된 표시 허용, 0.1.5의 입력초점 기반 보호를 유지한다. 작은 수동 탐색과 정상 표시 지연의 완전한 구분은 보장하지 않는다.
- 진행 정보가 없는 일반 영상은 지원 조건과 선택 옵션에 따라 시간제/추정/수동 대기로 나뉜다. 3초 미만·지원하지 않는 시간 표현·특수 콘텐츠·앱 UI 변경은 완주 감지 실패/대기가 가능하다. 재생 정보 없음 자체로 광고 판정을 하지 않는다.
- 회전·접기·펼치기 후 저장 위치를 현재 화면 안으로 보정하는 정책과 실제 실기기 전환 성공은 별도 검증 항목이다.

## 6. UI·플로팅 규격

상세 근거와 감사 항목은 [UI_DESIGN](UI_DESIGN.md)에 기록한다.

- 설정은 사용할 앱 → 일반 영상·횟수로 넘김 → 진행 정보 없는 영상·시간제로 넘김 → 광고·바로 넘김 → 플로팅 리모컨 → 사용 준비 → 실험 기능 순서다.
- ‘전체 자동 넘김 실행’과 상태는 하단 고정하여 어느 위치에서든 모든 동작을 끌 수 있게 한다. 과거 명칭 변경 제안은 0.2.4의 기능별 UI 승인으로 적용했으며 높이 축소·전체 기기 사용성 완료까지 뜻하지 않는다.
- 숫자는 큰 입력창, ▲▼는 각각52dp 높이, 앱 선택 행은 최소56dp, 일반 버튼은 최소48dp로 구현한다.
- 플로팅 OFF이면 관련 터치 방식 설정을 숨기되 값을 지우지 않는다.
- 시간제와 광고를 별도 카드로 나눈다. Instagram 미선택 시 조작은 비활성화하고 값을 보존한다. 시간제는 기본 OFF·10초·5~60초·0회 중지·완주 미보장을 설명한다. 광고는 기본 OFF·Instagram 한정·횟수와 별개·0회에서도 가능·끄면 직접 넘김을 설명한다.
- 광고 카드에 ‘반복 0회 + 광고 켜기 + 전체 실행 켜기’ 예시를 표시한다. 빠른 설정도 M=0/A=ON/Instagram 선택이면 ‘0회 · 광고만 넘김’, 그 외 0회는 ‘넘김 대기’로 구분한다.
- 화면 분석은 별도 실험 카드에서 Android 14 이상·동의·정확도 한계·시간제 우선순위를 설명한다. 렌더링/상태 복원으로 동의 창이 열리거나 옵션이 새로 켜지지 않게 한다.
- 네이티브 Android 위젯과 공통 색상/여백 모듈을 사용한다. Figma 산출물을 사용한 것으로 표기하지 않는다.
- 플로팅 전체72×56dp, 숫자 터치/드래그48×56dp, X24×24dp. 보이지 않는 외곽 터치 영역을 확대해 폭 축소를 위장하지 않는다.
- X24dp는 일반적인48dp 터치 목표보다 작은 사용자 승인 예외이다. 인앱·타일의 큰 종료 조작을 대안으로 유지한다.
- 배경의 알파128/255에 창 알파0.8을 곱하여 실효 배경 불투명도 약40%를 의도한다. 불투명한 숫자·X는 창 알파에 따라 약80%이며 실제 가독성은 영상 배경별로 검증한다.
- 플로팅 숫자 자동 크기 조절로99/99 같은 두 자리 분자·분모를 처리하되 작은 글자/큰 시스템 글꼴 조건은 시각 검증이 필요하다.

## 7. 저장·이전 계약

주요 키는 `ceiling`, `target`, `tap_mode`, `floating_enabled`, `youtube_enabled`, `instagram_enabled`, `skip_ads`, `timed_fallback`, `fallback_seconds`, `visual_assist`, `enabled`, `last_nonzero`, `x`, `y`, `settings_version`이다. 설정 스키마는1을 유지하고 새 선택 옵션은 안전한 getter 기본값을 사용한다.

- 기존 양수 target은 N/M에 함께 이전한다.
- 기존 target=0은 M=0을 보존하고 마지막 양수 값을 N으로 이전한다. 유효한 값이 없으면 N=2이다.
- 기본 YouTube 선택/Instagram 미선택/F=ON/ROTARY이다. 위치와 무관한 기존 값은 보존한다.
- `skip_ads`/`timed_fallback`/`visual_assist`가 없거나 올바른 boolean이 아니면 false로 읽는다. 기존 값은 이전 과정에서 지우거나 기본값으로 덮어쓰지 않는다. 광고 0회 독립 변경 후 기존 A=ON의 효과를 사용자에게 안내한다.
- `fallback_seconds`가 없거나 타입/범위가 손상됐으면 정책 기본값 10초로 읽는다. 정상 UI는 오류 입력을 10으로 몰래 확정하지 않고 오류를 표시한다. 15초/5~120초는 과거 후보 A이며 최신 범위 밖 값은 그대로 실행하지 않는다.
- 이전은 같은 설정에 반복 적용하지 않는다. 새 버전 설정을 구버전 기준으로 덮어쓰지 않는다.
- 현재값 target 변경은 N을 바꾸지 않는다. 기준 변경은 N/M을 함께 변경한다.
- 저장소 단위시험의 메모리 기반 SharedPreferences 검증은 Android 실제 디스크 저장·업데이트 설치·재시작 검증을 대체하지 않는다.

## 8. 0.1.5에서 변경된 기준

0.1.5의 0/1/2 전용·고정 순환·항상 플로팅 표시·타일 ON 시 마지막 양수 복원 규칙은 위의 N/M·두 모드·선택 표시·기준값 복원 규칙으로 변경한다. 기존72% 전체창 불투명도와 숫자/X 각각48dp 규격은 더 작고 투명한 플로팅 요청에 따라 변경했다. X 예외는 별도 승인된 절충이다.

과거 YouTube에서 검증한 완주·상향 스와이프·포커스 보호 결과는 유지할 회귀 근거이지, 신규 Instagram/입력 UI/0회 타일 의미까지 검증 완료됐다는 뜻은 아니다. 버전별 실제 결과는 누적 검증 기록을 따른다.

0.2.0의 ‘광고에서는 항상 대기’는 0.2.1의 별도 광고 옵션으로 변경했다. 0.2.4는 **0회에서도 광고만 사용 가능**으로 추가 변경했으며 옵션 기본 OFF와 기존 저장값 보존은 유지한다. 기존 A=ON이면 새 버전의 M=0 동작도 달라지므로 ‘업데이트 후 동작 불변’으로 설명하지 않는다. 정보 없는 지원 Instagram 영상은 새 선택형 시간제 또는 보존된 화면 분석 시험 경로를 사용할 수 있고 그 외는 수동 대기다.

## 9. 구조·개인정보·배포

core(순수 시간/반복/모드/입력/앱전환 정책), detection(앱별 접근성 조회와 선택 라우팅), service(관측·스와이프 조정), data(설정), overlay(숫자·드래그), tile(빠른 설정), ui(화면·입력·권한 바인딩)를 분리한다. Java/native Android를 유지하며 Kotlin/Compose나 외부 서비스를 추가하지 않는다.

인터넷·저장소·알림 권한 없음. 영상 내용·계정·시청이력은 외부 전송·영구 저장하지 않는다. 비교용 지문은 실행 메모리에만 보유한다. 화면 분석은 별도 승인된 접근성 screenshot capability를 쓰는 선택 시험이며 시간제 자체가 새 캡처/오디오 권한을 요구하지 않는다.

기존 Public 저장소의 0.2.4 시험판 공개는 사용자 승인 범위이며 20연속 미완료를 숨기지 않는다. 최종 게시·소스/산출물/CI·해시 일치는 릴리스 기록에 따르고 문서만으로 게시 완료라고 하지 않는다. 개인 화면·계정·기기 원본 로그·서명 개인키는 공개 대상에서 제외한다. 메일 발송은 별도이며 이번 공개 승인으로 추론하지 않는다.
