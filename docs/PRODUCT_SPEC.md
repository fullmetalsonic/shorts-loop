# 제품 기준 · ShortsLoop 0.2.2

0.2.2 추가 계약: 사용 준비에서 자기 앱의 Android 배터리 예외 상태를 읽고, 안내 후 자기 앱 상세 설정을 연다. 사용자가 배터리 → 제한 없음을 선택하며 시스템 정책 자동 변경·새 권한·실행 자동 재시작을 하지 않는다. Activity 복귀 시 재조회, 조회 실패 시 '확인 불가', 설정 이동 실패 시 수동 안내. 예외 미적용 자체가 실행을 차단하지 않으며 모든 절전 정책·PiP 지원·자동 넘김 안정성의 보증으로 표시하지 않는다.

이 문서는 0.2.1의 승인된 동작 계약과 구현 기준이다. 시험 완료 선언이 아니며 실기기·빌드·독립 리뷰 결과는 [VERIFICATION](VERIFICATION.md)을 기준으로 한다. [사용 설명서](USER_GUIDE.md), [UI·인간공학 기준](UI_DESIGN.md), [최초 업데이트 조사](UPDATE_PLAN_2026-08-27.md), [광고 기능 승인 설계](ADS_PLAN_2026-08-27.md)를 함께 관리한다.

## 1. 대상과 승인 범위

일반 YouTube 앱의 쇼츠 및 Instagram 앱의 지원되는 단일 동영상 릴스를 처음부터 설정 횟수만큼 관측한 뒤 다음 영상으로 이동한다. 사용자는 YouTube Premium을 사용한다고 설명했다. 0.2.1은 별도 승인에 따라 인식된 Instagram 광고의 다음 페이지 이동을 선택 제공한다. 광고 제거/네트워크 차단·YouTube 광고 처리·타사 앱 개조·외부 네트워크 전송은 범위 밖이다.

사용자가 승인한 0.2.0 변경은 다음과 같다.

- 기준 횟수 0~99, 숫자 직접 입력과 위/아래 화살표.
- 0의 의미를 ‘자동 넘김 안 함’으로 명시.
- 기준까지 순환 또는 0↔기준 전환의 두 플로팅 터치 방식.
- YouTube/Instagram 다중 선택 및 플로팅 표시 선택.
- 인앱 실행 토글 하나와 빠른 설정 연동.
- 플로팅 폭 축소와 투명도 증가, 작은 모서리 X 예외.
- 제공된 앱 아이콘 사진과 일체감 있는 남색·청색·보라색 계열 및 직관적인 인앱 구성.

0.2.1 추가 승인: Instagram 광고임을 확인하면 한 번의 완주도 기다리지 않고 다음 페이지로 이동하며, 별도 ON/OFF 토글과 안전한 기본 OFF를 제공한다. 재생바 없는 일반 릴스의 임의 넘김은 승인 범위가 아니다.

## 2. 상태와 용어

| 값 | 의미·범위 |
|---|---|
| 기준 N | 인앱에서 확정한 총 재생 횟수, 0~99 |
| 현재 M | 실제 영상에 적용하는 횟수, 0~N |
| 현재 회차 C | 완주를 추적 중인 회차, 0~M |
| 실행 E | 실행 제어 ON/OFF. M=0과 구분 |
| 플로팅 F | 표시 사용 설정. 실행 여부와 독립 |
| 터치 방식 | ROTARY=0: 0…N 순환 / TOGGLE=1: 0↔N |
| 적용 앱 | YouTube·Instagram 각각 선택, 기본 YouTube만 |
| 광고 옵션 A | `skip_ads` ON/OFF, 기본 OFF. Instagram에만 적용 |

플로팅은 C/M만 표시한다. N=5, M=2이면 `1/2`·`2/2`이며 기준 5는 보존한다. 앱은 필요할 때 기준/현재 값의 차이를 별도로 설명한다.

0은 실행 전체 종료가 아니라 광고를 포함한 모든 자동 넘김 대기 값이다. E=ON/M=0이면 플로팅 재조작을 위해 제어를 켜 둔다. 하단 실행은 켜짐, 상태 문구는 ‘0회, 자동 넘김 안 함’이다. E=OFF이면 플로팅도 닫는다.

## 3. 입력·실행 전이 계약

| 조작 | 저장과 실행 결과 |
|---|---|
| 숫자 타이핑 | 임시 입력. 저장값·진행 설정 즉시 변경 안 함 |
| 완료/적용 | 0~99 정수만 N/M에 함께 저장, 횟수 초기화 |
| ▲/▼ | 유효한 입력에서 ±1 후 0~99 범위로 즉시 적용 |
| 잘못된 입력 | 적용 차단·설명. 빈칸을 0으로 저장하지 않음 |
| 인앱 실행 ON | 임시 입력 검증 후 M=N, E=ON. 앱 선택·설치·권한 확인 |
| 빠른 설정 ON | M=N, E=ON. 접근성·앱 선택·필요한 표시 권한 확인 |
| 실행 OFF/타일 OFF/X | E=OFF, 플로팅 닫기. N/M/F/위치 보존 |
| ROTARY 숫자 탭 | M<N이면 M+1, M=N이면0. N 보존 |
| TOGGLE 숫자 탭 | M=0이면 N, M>0이면0. N 보존 |
| 터치 방식 변경 | 방식 저장, M=N으로 맞춤, 횟수 초기화 |
| F OFF | 표시만 숨김. E/M/진행 추적 자체는 유지 |
| F ON | 실행 중이면 권한 확인 후 표시. 권한 없으면 안전 정지 |
| 앱 선택 변경 | 이전 추적 초기화. 전부 해제하면 실행 중지 |
| 광고 옵션 변경 | A만 저장. N/M/E를 변경하거나 실행을 새로 켜지 않음 |
| Instagram 선택 해제 | 광고 토글 조작 비활성. A 저장값은 보존하고 광고 동작은 금지 |
| 숫자 드래그 | 횟수 추적 보류/초기화, 상대 위치 저장. 탭으로 오인하지 않음 |

N=0이면 M도0이며 실행 ON이나 플로팅 탭이 과거 양수 설정을 복원하지 않는다. 플로팅 표시 OFF는 카운트를 초기화하는 설정이 아니지만, 설정 앱으로 전환하는 행위 자체는 대상 영상 앱을 벗어나므로 앱 전환 보호가 적용된다.

잘못된 저장값은 순수 정책으로 정규화한다. 정상 입력 UI에서는 잘못된 숫자를 임의 기본값으로 확정하지 않고 오류를 보여 준다. 기준 N과 현재 M 등 함께 변경되는 값은 SharedPreferences의 한 Editor로 갱신한다.

## 4. 감지와 자동 넘김

- 선택된 앱 패키지와 포커스를 확인한 다음 해당 앱 전용 감지기를 호출한다. 두 앱이 선택되어도 현재 앞에 있는 앱만 대상이다.
- YouTube는 쇼츠 컨테이너와 단일 진행막대의 최신 시간을 확인한다.
- Instagram은 릴스 pager 내부의 단일 영상 컨테이너, 단일 media, `scrubber` 진행막대와 유효한 밀리초 범위를 확인한다.
- 일반 Instagram 릴스의 사진/혼합 콘텐츠, 댓글/메뉴, 유효하지 않은 진행값 또는 영상 식별 정보 부족을 감지하면 대기한다. 별도로 확인된 광고만 아래의 즉시 넘김 계약을 적용한다. 모든 광고·메뉴 유형을 판별한다고 보장하지 않는다.
- 앱 패키지를 포함한 식별값으로 영상과 앱을 구분한다. 앱 전환 때 진행 상태를 초기화하여 다른 앱의 카운트를 이어 쓰지 않는다.
- 약 300ms 간격으로 관측하고, 영상 끝→처음 이동·관측 진행량·최소 경과시간을 함께 확인한다. 단순 시간 타이머로 넘기지 않는다.
- 중간에 켜면 현재 부분 재생은 완주로 세지 않는다. 다음 시작까지 C=0, 추적 중 C=1…M이다.
- 일반 영상의 자동 제스처는 영상 영역 높이 75%에서25%까지 아래→위로 이동한다. 플로팅 영역을 피하며 시스템 모서리에서 시작하지 않는다. 광고는 좌표 제스처 대신 아래의 pager 동작을 사용한다.
- 스와이프 요청 성공과 다음 영상 전환 성공을 구분한다. 전환이 확인되지 않으면 연속 재시도하지 않고 재시작 안내 상태로 멈춘다.

### Instagram 광고 즉시 넘김 계약

- E=ON, M>0, Instagram 선택, A=ON을 모두 만족하고 현재 전면의 Instagram 릴스에서 광고 근거와 안전한 화면 구조를 확인해야 한다.
- 기본 A=OFF이고0회는 광고까지 중지한다. 옵션 변경은 N/M/E를 바꾸지 않는다.
- 광고 라벨·컨테이너 구조를 검사한다. 캡션·작성자·본문에 ‘광고’라는 단어가 있거나 재생바가 없다는 이유만으로 광고로 간주하지 않는다.
- 실측된 우하단 동영상 광고 배지는 `clips_ufi_component` 내부의 작은 라벨이고 클릭 가능한 부모 영역이 라벨보다 클 수 있다. 해당 구조·위치·라벨의 정확한 일치를 함께 검사한다. 일반 캡션의 `#광고`만으로 이 구조를 대체하지 않는다.
- 광고를 발견해도 전체 화면의 댓글/메뉴/복수 pager/지원하지 않는 구조 검사를 생략하지 않는다.
- 새로 조회한 정확한 릴스 pager에 `ACTION_SCROLL_FORWARD`를1회 요청한다. 광고 링크·CTA·구매 버튼에 클릭 동작을 보내지 않으며 거절 시 좌표 스와이프로 대체하지 않는다.
- 릴스 영상 위의 ‘더 알아보기’ CTA 카드가 있는 광고는 페이지 전체 넘김 대상이다. 별도 창 팝업의 X를 찾아 닫는 기능은 미구현이며 범위 미확정이다.
- 광고는 진행시간 없이 구조로 인식한 페이지이다. 일반 영상도 시간값이 없지만 확실한 단일 영상·식별정보가 있으면 이전 요청의 전환 확인에만 사용하며 새 자동 넘김 근거로 사용하지 않는다.
- 요청 중에는 추가 요청을 금지한다. API가true를 반환했다고 성공으로 확정하지 않는다. 최소1.2초 이후 다른 페이지를 확인하며4.5초까지 확인되지 않으면 안전 정지한다.
- 광고끼리 고정 식별값을 공유하므로 늦은 페이지 이동 이벤트만으로 연속 광고를 성공 처리하지 않는다. 다른 광고임을 구분할 수 없으면 실제로 이동했어도 안전 정지할 수 있다. 같은 광고·무정보·null 상태에서 무한 재시도하지 않는다.
- 이동 확인 pending 도중 화면 구성 변경·드래그 등 세션 중단은 단순 gate 취소로 새 요청을 허용하지 않는다. `interruptSession`을 통해 확인 중이면 안전 정지하고, 확인 중이 아니면 정상 초기화한다. 독립 검토에서 지적한 중복 광고 요청 위험에 대한 보완이다.

시험 빌드v021b에서 아래 항목을 확인했다. 동일한 표시 버전0.2.1이라도 후속 보완 빌드v021c의 결과로 바꿔 적지 않는다.

시각은 상태 관측시각이며 첫 pending 표본을 실제 요청 시작시각으로 간주하지 않는다. N=0에서는 앱/시간 조회를 중단하므로 진단에 남은 앱·재생시간만으로 현재 화면을 판정하지 않고 실제 화면 확인과 함께 평가한다. 광고 CTA 카드를 클릭하지 않고 pager 동작으로 전체 광고를 넘긴 것을 확인했다.

v021b의145개 시험 이후 독립 검토의 pending 중단 위험을 보완했다. 최종v021c 빌드·직접JUnit148·정적연결검사·독립 재리뷰 PASS, 설치본 해시 일치. YouTube43초→5초→43초 N1, 빠른 설정 타일 OFF/ON, Instagram 미선택 대기는 실제 PASS. pending 순간 회전·드래그와 장시간/모든 광고형태는 아직 실기기 완료가 아니다. 상세 범위는 검증 문서에 기록한다.

## 5. 안전·정확도 제한

- 선택 앱의 지원 화면, 유효한 진행 정보 또는 별도로 입증된 광고, 화면 켜짐/잠금 해제, 입력초점 조건을 만족할 때만 자동 동작한다.
- 댓글·키보드·메뉴·앱 전환·드래그·영상 변경·긴 관측 공백·수동 탐색으로 판단한 점프는 보수적으로 추적을 초기화한다.
- 일반 영상의 일시정지·버퍼링 동안 시간 경과만으로 넘기지 않는다. 광고 즉시 넘김은 재생 완주와 독립이다.
- 현재값 변경·X·OFF는 이전 추적/예약 동작보다 우선한다. 플로팅 표시 변경은 별도 표시 경로이다.
- 프로세스나 접근성 서비스가 다시 연결되면 자동 실행하지 않고 E=OFF로 시작한다.
- 빠른 설정창·다른 포커스 창·PiP에서는 대기한다. 다른 앱의 비포커스 플로팅이나 팝업 가림을 전부 판별한다고 보장하지 않는다.
- 0.1.4의 최신 접근성 시간 갱신·양자화된 표시 허용, 0.1.5의 입력초점 기반 보호를 유지한다. 작은 수동 탐색과 정상 표시 지연의 완전한 구분은 보장하지 않는다.
- 진행 정보가 없는 일반 영상,3초 미만 일반 영상, 지원하지 않는 시간 표현·특수 콘텐츠·앱 UI 변경은 완주 감지 실패/대기가 가능하다. 재생 정보 없음 자체로 광고 판정을 하지 않는다.
- 회전·접기·펼치기 후 저장 위치를 현재 화면 안으로 보정하는 정책과 실제 실기기 전환 성공은 별도 검증 항목이다.

## 6. UI·플로팅 규격

상세 근거와 감사 항목은 [UI_DESIGN](UI_DESIGN.md)에 기록한다.

- 설정은 반복 횟수 → 사용할 앱 → 선택적 플로팅 → 사용 준비 순서이며 실행/상태는 하단 고정한다.
- 하단 고정은 설정 중 어느 위치에서든 상태 확인·종료가 가능하게 하는 목적이다. 높이 축소와 ‘전체 자동 넘김’ 명칭은 제안만 했으며 추가 변경 승인 없이 적용하지 않는다.
- 숫자는 큰 입력창, ▲▼는 각각52dp 높이, 앱 선택 행은 최소56dp, 일반 버튼은 최소48dp로 구현한다.
- 플로팅 OFF이면 관련 터치 방식 설정을 숨기되 값을 지우지 않는다.
- 광고 토글은 사용할 앱 카드 안에 표시하고 Instagram이 선택된 경우에만 조작할 수 있게 한다. 기본 OFF·Instagram 한정·실행ON/1회 이상 조건·끄면 광고 직접 넘김·일반 릴스 수동 넘김 한계를 함께 설명한다.
- 네이티브 Android 위젯과 공통 색상/여백 모듈을 사용한다. Figma 산출물을 사용한 것으로 표기하지 않는다.
- 플로팅 전체72×56dp, 숫자 터치/드래그48×56dp, X24×24dp. 보이지 않는 외곽 터치 영역을 확대해 폭 축소를 위장하지 않는다.
- X24dp는 일반적인48dp 터치 목표보다 작은 사용자 승인 예외이다. 인앱·타일의 큰 종료 조작을 대안으로 유지한다.
- 배경의 알파128/255에 창 알파0.8을 곱하여 실효 배경 불투명도 약40%를 의도한다. 불투명한 숫자·X는 창 알파에 따라 약80%이며 실제 가독성은 영상 배경별로 검증한다.
- 플로팅 숫자 자동 크기 조절로99/99 같은 두 자리 분자·분모를 처리하되 작은 글자/큰 시스템 글꼴 조건은 시각 검증이 필요하다.

## 7. 저장·이전 계약

주요 키는 `ceiling`, `target`, `tap_mode`, `floating_enabled`, `youtube_enabled`, `instagram_enabled`, `skip_ads`, `enabled`, `last_nonzero`, `x`, `y`, `settings_version`이다. 현재 설정 스키마는1이며0.2.1 광고 옵션 추가로 올리지 않는다.

- 기존 양수 target은 N/M에 함께 이전한다.
- 기존 target=0은 M=0을 보존하고 마지막 양수 값을 N으로 이전한다. 유효한 값이 없으면 N=2이다.
- 기본 YouTube 선택/Instagram 미선택/F=ON/ROTARY이다. 위치와 무관한 기존 값은 보존한다.
- `skip_ads`가 없거나 올바른boolean이 아니면false로 읽는다. 기존 값이 있다면 이전 과정에서 지우거나 다시 기본값으로 덮어쓰지 않는다.
- 이전은 같은 설정에 반복 적용하지 않는다. 새 버전 설정을 구버전 기준으로 덮어쓰지 않는다.
- 현재값 target 변경은 N을 바꾸지 않는다. 기준 변경은 N/M을 함께 변경한다.
- 저장소 단위시험의 메모리 기반 SharedPreferences 검증은 Android 실제 디스크 저장·업데이트 설치·재시작 검증을 대체하지 않는다.

## 8. 0.1.5에서 변경된 기준

0.1.5의 0/1/2 전용·고정 순환·항상 플로팅 표시·타일 ON 시 마지막 양수 복원 규칙은 위의 N/M·두 모드·선택 표시·기준값 복원 규칙으로 변경한다. 기존72% 전체창 불투명도와 숫자/X 각각48dp 규격은 더 작고 투명한 플로팅 요청에 따라 변경했다. X 예외는 별도 승인된 절충이다.

과거 YouTube에서 검증한 완주·상향 스와이프·포커스 보호 결과는 유지할 회귀 근거이지, 신규 Instagram/입력 UI/0회 타일 의미까지 검증 완료됐다는 뜻은 아니다. 버전별 실제 결과는 누적 검증 기록을 따른다.

0.2.0의 ‘광고에서는 항상 대기’ 기준은0.2.1의 별도 광고 옵션으로 변경한다. 일반 릴스의 재생 정보 부족은 여전히 수동 넘김 대상이다. 기본 OFF이므로 업데이트만으로 광고 동작을 새로 켜지 않는다.

## 9. 구조·개인정보·배포

core(순수 시간/반복/모드/입력/앱전환 정책), detection(앱별 접근성 조회와 선택 라우팅), service(관측·스와이프 조정), data(설정), overlay(숫자·드래그), tile(빠른 설정), ui(화면·입력·권한 바인딩)를 분리한다. Java/native Android를 유지하며 Kotlin/Compose나 외부 서비스를 추가하지 않는다.

인터넷·저장소·알림 권한 없음. 영상 내용·계정·시청이력은 외부 전송·영구 저장하지 않는다. 비교용 지문은 실행 메모리에만 보유한다. GitHub 게시와 메일 발송은 이번 구현 승인에 포함되지 않는다. 현재 작업의 배포·발송 여부는 인수인계와 누적이력에 별도로 기록한다.
